Edit artwork only in `sources.py`. Run `sources.py` and then `generate.py` after a change. Do not hand edit generated SVG, PNG, ICO, ICNS, manifest, or desktop copies.

The outlined wordmark uses IBM Plex Serif and the tagline uses Figtree.

`raster/`, `svg/` and `web/` are generated output: regenerate rather than edit. `fonts/` keeps each input's provenance and license notice, and a text in `licenses/` changes only together with the font it covers.
